# dsh-pet（雷米埃尔桌宠）

DSH（DeepSeek Harness）桌宠插件：在 DSH 界面里养一只会跟随会话状态变装的桌宠。兼容 **Web UI 和桌面版**。

桌宠住在窗口右下角，AI 干活时它换装忙碌，空闲时它卖萌，需要你审批时它跳起来提醒你。

## 功能一览

- 🎭 **状态跟随**：实时检测 DSH 会话状态，自动切换对应 GIF（见下文状态表）
- 🖱️ **互动**：单击/双击摸头冒爱心，拖动调整位置，右键直达设置
- 📌 **位置记忆**：位置以「距窗口右下角偏移」保存，窗口缩放、最大化、重启后都跟着右下角走
- 🔔 **审批提醒**：有待审批/提问时弹跳提醒，可配提示音
- 🎨 **自定义 GIF**：每个状态可单独上传自己的 GIF（透明底效果最佳）
- 🌈 **兜底显示**：GIF 加载失败时显示按状态着色的呼吸小脸，永不消失

## 状态与 GIF 对应表

| 优先级 | 设置面板标签 | 默认 GIF | 什么时候显示 |
|---|---|---|---|
| 1（最高） | 待审核 | approval.gif | 弹出工具审批、AI 向你提问、计划评审时 |
| 2 | 编辑中 | answering.gif | AI 正在产出：流式输出文字、写文件/编辑代码/执行命令等工具调用 |
| 3 | 思考中 | thinking.gif | 会话在运行但暂无产出：等第一个 token、深度思考（reasoning）流式、步骤间隙、模型重试 |
| 4 | 空闲中 | idle.gif | 未在运行，或回合已结束 |

一轮典型对话的切换顺序：

```
发消息 → 思考中（等首 token / 深度思考）→ 编辑中（输出文字、写文件、跑工具）
       →（弹出审批）待审核 → 批准后回到编辑中 → 回合结束 → 空闲中
```

> 已知盲区（表现为空闲中）：切到 Trajectory 标签页时、后台自动压缩期间——这两种场景 DSH 前端不提供运行标记。

## 安装

### 方式 1：GitHub 地址（推荐）

DSH 设置 → 插件 → 添加插件，输入：

```
github:Shinarin/dsh-pet
```

或命令行：

```bash
dsh plugin add github:Shinarin/dsh-pet
```

### 方式 2：本地路径

```bash
dsh plugin add <本仓库本地路径>
```

> ⚠️ 安装或更新后，**完全退出并重启 DSH** 使插件生效。

### 卸载

DSH 设置 → 插件 → 找到 dsh-pet → 卸载。

## 使用方式

| 操作 | 效果 |
|---|---|
| 拖动 | 移动桌宠；松手后位置自动保存，窗口缩放/重启后仍锚定右下角 |
| 单击 | 摸头，冒爱心 💕 |
| 双击 | 触发「双击动作」（当前可选：摸头冒爱心） |
| 右键 | 打开桌宠设置 |

首次打开时，桌宠默认出现在**窗口右下角往左 100px、往上 200px** 的位置。拖动过一次后记住你的位置。

桌宠右上角有一个状态小圆点：🟢 空闲 / 🟠 思考中 / 🔵 编辑中 / 🔴 待审核。

## 设置

DSH 设置面板 → **桌宠设置**：

![设置面板](docs/settings.png)

| 选项 | 说明 | 默认值 |
|---|---|---|
| 显示 | 显示/隐藏桌宠 | 显示 |
| 大小 | 50% – 250% | 100% |
| 双击 | 双击时触发的动作 | 摸头冒爱心 |
| 审批提醒：弹跳 | 出现待审批/提问/评审时弹跳 | 开 |
| 审批提醒：提示音 | 审批时播放提示音 | 关 |
| 完成提醒：弹跳 / 提示音 | ⚠️ 当前版本未接入触发（已知问题，设置保留） | 开 / 开 |
| 各状态 GIF | 为四种状态分别上传自定义 GIF，可随时「清除」恢复默认 | 内置默认 |

### 自定义 GIF 小贴士

- 推荐**透明底 GIF**，融入界面最自然
- 自定义 GIF 以 base64 存在本机 localStorage，不上传任何服务器
- 过大的 GIF（数 MB）会拖慢切换，建议控制在 1MB 以内
- 「清除」按钮可一键恢复该状态的内置默认 GIF

## 常见问题

**Q：重启 DSH 后桌宠不出现？**
A：升级最新版后已修复（旧版把位置存成绝对像素，窗口变化后桌宠落在屏幕外）。如果仍不见，到「桌宠设置」把显示开关关掉再打开，或拖一下窗口边缘触发重排。

**Q：状态切换不准？**
A：DSH 前端是 nightly 通道，DOM 结构可能随版本漂移。打开 DSH 开发者工具控制台，过滤 `[DSH-PET]` 日志（含每次状态切换的判定依据），把日志连同场景描述提到 [Issues](https://github.com/Shinarin/dsh-pet/issues)。

**Q：为什么 AI 深度思考时显示「思考中」而不是「编辑中」？**
A：产品规则如此划分：reasoning 流式归「思考中」，只有文本输出和工具执行归「编辑中」。

**Q：桌面版 GIF 显示为彩色小脸？**
A：那是兜底占位符，说明 GIF 加载失败（通常是插件服务端未就绪）。稍等片刻或重启 DSH；一直如此请到 Issues 反馈。

## 工作原理（简述）

- **客户端**（`client.js`）：`MutationObserver` + 500ms 轮询读取 DSH 前端 DOM 的稳定契约（`data-*` 属性与 aria-label，不依赖 CSS 类名和按钮文案），推断四种状态后切换浮层 GIF
- **服务端**（`lib/index.js`）：注册 `/pet/default-gif/:state`（内置 GIF 静态服务）与 `/pet/config`（配置持久化）路由
- 状态检测的完整契约与 DSH 源码出处见 [`spec/state-detection.md`](spec/state-detection.md)

```
  development.md        # 开发者文档
  devlog.md             # 开发日志
  debug.md              # 坑点记录
```
